
# Taifa eCitizen — Public Service Request Portal
A beginner-friendly, Kenyan-inspired front-end prototype built with HTML, CSS, and JavaScript.

# Run Locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` with the VS Code Live Server extension, or open it in a browser.
3. Register an example account using fictional details.
4. Explore service cards, submit an example request, view My Requests, and test reference tracking.

Limitations
This is an educational prototype, not an official Government of Kenya website.

No real government services, identity verification, email, database, or M-Pesa payment are connected.

Example data is stored in the browser’s local storage. Do not enter sensitive information or reuse real passwords.

The hero background uses an externally hosted Unsplash image (requires internet). A gradient fallback is included if the image fails to load.
